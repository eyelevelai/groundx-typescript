# AGENTS.md — groundx-typescript

Official GroundX TypeScript SDK. Most files are generated by Fern from
`eyelevel-fern-config`.

## Boundaries

- Before editing, read `.fernignore`. Only edit files protected by it or files
  that are intentionally repo-authored.
- API surface, model, endpoint, SDK naming, dependency, or generator behavior
  changes belong upstream in `eyelevel-fern-config` or Fern, then arrive here
  through regeneration.
- Do not hand-edit generated reference or client files.

## Comment Hygiene

Use comments for non-obvious behavior, invariants, or risk. Do not commit PR
history, ticket rationale, implementation-plan prose, or "this test proves..."
narration in code or tests; put that context in Linear, OpenSpec, the PR body,
or docs.
